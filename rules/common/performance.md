# Performance and model selection

Use the host's configured model by default. Select an override only when availability,
capability, cost, and authorization are known. Never infer prices or capabilities from names.
Keep routine tasks small; reserve deeper reasoning for ambiguous architecture and security.
Read focused context and checkpoint long tasks. Use independent bounded agents only when
supported and useful, with explicit ownership and stopping conditions.
Measure performance before optimizing. Fix build failures incrementally and rerun checks.
